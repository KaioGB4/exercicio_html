# 📝 Formulário de Cadastro Simples

Este projeto consiste em um formulário de cadastro estruturado em HTML5 puro. O objetivo é demonstrar a organização semântica de elementos de entrada de dados e a criação de interfaces de usuário básicas.

## 🚀 Sobre o Projeto
O projeto faz parte dos meus estudos fundamentais de desenvolvimento web, focando na estruturação de formulários para coleta de informações (Nome, E-mail e Senha).

## 🛠️ Tecnologias Utilizadas
* **HTML5**: Estruturação semântica da página.

## 📋 Funcionalidades
* Campo de entrada para **Nome**.
* Campo de entrada para **E-mail** (com validação nativa de tipo).
* Campo de entrada para **Senha** (com máscara de caracteres).
* Botão de envio para submissão dos dados.
